## 💬 ¿Discussions, Issues o formulario?

- Utiliza **[Discussions](https://github.com/orgs/gdg-caracas/discussions)** para conversar, formular preguntas, compartir ideas, proponer temas y ofrecer feedback.
- Utiliza **Issues** para tareas o problemas concretos relacionados con un repositorio o proyecto específico.
- Utiliza el **[formulario de participación](https://docs.google.com/forms/d/e/1FAIpQLSeXzVXmdXwpjDpw_8ssFZYNFus1eAF9WeonaAnqvcQz4olUCQ/viewform?usp=header)** para enviar formalmente propuestas de charlas, talleres, paneles o codelabs.

> Publicar una idea en Discussions permite conversar sobre ella, pero no sustituye el envío del formulario formal.

## 🤝 Normas de participación

- Comunícate con respeto, empatía e inclusión.
- Publica cada tema en la categoría correspondiente.
- Evita el spam y la promoción sin contexto para la comunidad.
- No compartas información personal, privada o sensible.
- Respeta la autoría y cita las fuentes de los recursos compartidos.
- Ofrece feedback claro, amable y constructivo.
- Sigue las [GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines) y las normas de convivencia de GDG.
